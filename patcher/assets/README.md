# Данные патча

| Файл | Размер | Что внутри |
|---|---:|---|
| `exe_patch.bin` | 103 467 | точечные изменения `Gunpoint.exe` + русские строки |
| `wad_patch.bin` | 770 018 | 12 полных `.fnt` + 13 range diff |
| `gpc_patch.bin` | 46 416 | 44 `.gpc` в CP1251 |
| `manifest.bin` | — | хэши/размеры, список `.gpc` |

Это **не** полные игровые файлы:

- `.fnt` — изменённая XML-метаинформация шрифтов;
- `.phyre` в `wad_patch.bin` хранятся как диапазоны изменённых пикселей,
  а не полные атласы;
- `exe_patch.bin` не содержит `Gunpoint.exe` целиком — только точечные
  изменения и наш пул переводов;
- `gpc_patch.bin` — наш текст перевода.

Данные получены из легально принадлежащей копии Gunpoint 1.82 и
пропатченной сборки перевода. Они включены только для того, чтобы
патчер можно было собрать и проверить. Права на исходные игровые
ассеты принадлежат Suspicious Developments.

Для обычной сборки патчера перегенерация не требуется.
