**Русская локализация Gunpoint 1.82 для Steam (AppID 206190).**

Переводит интерфейс, телефонные звонки, письма, магазин, управление,
подсказки, описания предметов и все 44 сценарных `.gpc`-файла.

> Это фанатский перевод. Нужна лицензионная копия игры. Проект не связан
> с Suspicious Developments или Valve.

## Что делает патчер

- Проверяет, что у вас Steam-версия Gunpoint **1.82** (по SHA-256).
- Создаёт резервную копию.
- Патчит **вашу** копию:
  - `Gunpoint.exe` — добавляет русские строки интерфейса и исправляет
    отображение кириллицы;
  - `Gunpoint.wad` — добавляет кириллические глифы в 12 шрифтов;
  - `Scripts\*.gpc` — переводит 44 файла диалогов.
- Проверяет результат по контрольным суммам.
- Умеет восстанавливать оригинал.

Файлы игры не распространяются: патчер изменяет только вашу легальную
установку. Сейвы, достижения и Steam Cloud не затрагиваются.

## Требования

- Windows 10/11.
- Steam-версия Gunpoint **1.82**.
- Права администратора (игра обычно лежит в `Program Files (x86)`).
- ~1.5 ГБ свободного места на время установки.

## Установка

1. Закройте Gunpoint.
2. Скачайте [GunpointRU_Patcher.exe](dist/GunpointRU_Patcher.exe).
3. Запустите его. Windows запросит права администратора — разрешите.
4. Патчер сам найдёт игру через Steam. Если не нашёл — выберите папку
   `...\steamapps\common\Gunpoint`.
5. В меню выберите `[1] Установить русскую локализацию`.
6. Подтвердите `Y`.
7. Дождитесь `[1/4]…[4/4]` и сообщения «Готово».
8. Запустите игру из Steam.

### Меню патчера

```text
[1] Установить русскую локализацию
[2] Восстановить оригинал
[3] Выбрать папку вручную
[4] Проверить файлы
[0] Выход
```

- `[2]` возвращает оригинальные файлы из резервной копии.
- `[3]` нужен, если игра не найдена автоматически.
- `[4]` показывает состояние и проверяет 44 `.gpc`.

## Восстановление

- Пункт `[2]` в патчере, или
- Steam → Gunpoint → Свойства → Установленные файлы →
  «Проверить целостность файлов».

Бэкап:

```text
%LOCALAPPDATA%\GunpointRU\backup\backup-<время>\
```

## FAQ

**Steam снова показывает английский.**
Steam → «Проверить целостность файлов» откатывает патч. Запустите
установщик ещё раз.

**Антивирус ругается.**
Патчер — нативный exe без сетевого кода и упаковщиков, но он меняет
`Gunpoint.exe`, поэтому эвристика возможна. SHA-256 указан выше,
исходники — в `patcher/`.

**Игра установлена в другой библиотеке Steam.**
Патчер читает `libraryfolders.vdf` и проверяет все библиотеки. Если
автопоиск не сработал — выберите папку вручную.

**Достижения и облачные сохранения.**
Патч не трогает Steam API и сейвы. Достижения и Cloud остаются рабочими.

**GOG-версия.**
Не поддерживается: другие хэши `Gunpoint.exe`/`Gunpoint.wad`.
